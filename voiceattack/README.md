# DysonSphereProgram-VoiceAttack-Profile
A Voice Attack 2 Profile for Dyson Sphere Program

Say "wind turbine" and the profile opens the Power bar and picks the wind turbine for you, while
Icarus answers "Deploying wind turbine". It has 59 voice commands: buildings, panels, flying,
copy, screenshots and more. The full list is in [`docs/hotkey-map.csv`](docs/hotkey-map.csv).

Tested with VoiceAttack v2.2.0.3 on Windows.

## Before you start

You'll need:

- **Windows, and Dyson Sphere Program with its default key bindings.** Every command presses
  DSP's default keys. If you've rebound a key in the game, the matching command won't work until
  you rebind it back or change the command.
- **VoiceAttack 2, full version.** The free trial allows one profile with up to 20 commands, and
  this profile has 59. VoiceAttack is a one-time purchase from voiceattack.com or Steam.
- **A microphone and Windows speech recognition.** Running Windows' speech training makes
  recognition noticeably better.
- **For the Azure profile only:** an Azure Speech key, set up once in VoiceAttack. See
  [One-time Azure setup](docs/changing-the-voice.md#one-time-azure-setup). The local-voice profile
  doesn't need it.
- **To change the profiles yourself:** Python 3 (see [Making changes](#making-changes)).

Optional: the [Stream Deck profile](https://github.com/jgaryt/DysonSphereProgram-Stream-Deck-Profile)
puts the same commands on buttons.

## Quick start

1. **Pick a profile** from the `profiles` folder:

   | File | Icarus's voice | Use it if… |
   |---|---|---|
   | `DSP Build Hotkeys-Profile.vap` | Azure, `[Azure] Grant MAI-Voice-2.1-Flash (en-US)` | You've set up Azure voices in VoiceAttack (see [the voice guide](docs/changing-the-voice.md#one-time-azure-setup)) |
   | `DSP Build Hotkeys-LocalVoice-Profile.vap` | Your Windows default voice | You haven't set up Azure, or want instant replies |

   Both have the same commands.

2. **Import it.** In VoiceAttack, choose **Import Profile** from the profile actions menu (beside
   the profile name), pick the file, and switch to the new profile.

3. **Recommended:** in **Options → Text-to-Speech**, tick **Single TTS Instance**. If you can,
   send Icarus to your headset with **Override Default Text-to-Speech Device**. Both help stop
   replies piling up or being heard by the microphone.

4. Keep Dyson Sphere Program as the active window and start talking.

**Updating:** delete the old profile in VoiceAttack before importing a new version, or you'll get
every command twice. If you've changed the voice or effect set, re-apply it with Mass update. See
[the voice guide](docs/changing-the-voice.md).

## How to read the commands

The commands use VoiceAttack's phrase format. Square brackets list alternatives separated by `;`,
and a trailing `;` makes the group optional:

| Written as | You can say |
|---|---|
| `[build;place;] wind turbine` | "wind turbine", "build wind turbine", "place wind turbine" |
| `[conveyor belt;conveyor;belt] [two;mark two]` | "belt two", "conveyor mark two", "conveyor belt two", … |

Replies work the same way. `Deploying wind turbine;Constructing wind turbine` means Icarus says
one of the two at random.

## How the commands work

**Build commands press two bar keys.** In DSP, pressing a bar's number key when that bar is
already open closes it. So each build command first presses a *different* bar's key, then the
one it wants, then the F-key. That way it works whatever is open:

```
"wind turbine":  speak reply → 9 → 0.1 s → 1 → 0.1 s → F4
```

Bar 9 items use `8` as the first key instead. Everything else is a single key or a short
combination:
- Esc, U, X, Left Alt
- the panel keys
- Space twice for Fly
- Shift + left click for Copy
- Shift + F11 for Screenshot

**Icarus speaks first,** so his reply doesn't wait for the key presses.

**Replies never match a command.** VoiceAttack can hear Icarus through your speakers. If he said
"wireless tower" after you did, it would set off the command again, over and over. So build
replies start with "Deploying" or "Constructing", and the build script refuses to make a profile
if any reply matches a command.

## Making changes

Needs Python 3.

1. Edit `scripts/build_profile.py`:
   - **Build commands:** add the building to the `rows` list (name, bar key, F-key, phrase) and
     its reply to the `REPLY` dictionary.
   - **Panel commands:** add them to the `PANELS` list.
   - **Other actions** (fly, land, copy, screenshot, cancel, upgrade, dismantle): these are the
     `out.append(cmd(...))` lines next to `PANELS`.
2. Run `python scripts/build_profile.py`. It writes both profiles. If a reply matches a command,
   it stops and names the reply.
3. Update `docs/hotkey-map.csv` to match.
4. In VoiceAttack, delete the old profile and import the new one.

## Open items

- Identify the build-bar slots still marked **Guess** in `docs/hotkey-map.csv`, and add them as
  commands.
- Add commands as locked slots unlock.
